# Small Parcel Guaranteed Service Refund Recovery

Recover carrier service-guarantee refunds from late or failed parcel deliveries with contract and exception evidence.

**Primary buyer:** High-volume parcel shippers. **Evidence:** carrier agreements, manifests, tracking scans, service commitments, delivery timestamps, exceptions, weather events, invoices, refund requests, and credits.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Carrier agreement library
- Package manifest ingestion
- Tracking event timeline
- Service commitment calculation
- Delivery timestamp validation
- Late delivery detection
- Exception code validation
- Weather waiver review
- Peak waiver control
- Address correction audit
- Refund eligibility calculation
- Carrier refund submission
- Denial appeal workflow
- Credit invoice reconciliation
- Carrier service analytics

Run `./start.sh`, then open <http://127.0.0.1:4696>. API: `5696`.
